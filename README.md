# Vadodara Eats — SEO Tiny Project

## Project Objective
A practical local-food website created to demonstrate foundational SEO implementation.

## SEO Implementations
- Unique page titles and meta descriptions
- Relevant keyword targeting without keyword stuffing
- Semantic HTML5 structure
- Proper H1/H2/H3 hierarchy
- Internal linking
- Canonical URLs
- Open Graph metadata on the home page
- JSON-LD WebSite structured data
- robots.txt
- XML sitemap
- Mobile responsive design
- Lightweight static architecture
- Descriptive page content aligned with search intent

## Pages
- `index.html` — Home
- `cafes.html` — Cafe guide
- `food-guide.html` — Food guide
- `about.html` — Project objective and outcomes

## Deployment
This is a static website and can be deployed directly to Vercel, Netlify, GitHub Pages or any static hosting service.

## Important
Before final deployment, replace `https://example.com/` in canonical URLs, Open Graph data and `sitemap.xml` with the actual live domain.

## Interactive Dining Features
- 8 cafe/restaurant cards
- Type, budget and search filters
- Mini menus for every place
- Add-to-order interaction with running total
- Favourite buttons
- Sample table reservation form with date, time and guest selection
- Responsive navigation and UI
